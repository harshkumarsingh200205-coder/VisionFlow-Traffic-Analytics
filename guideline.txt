1. PROJECT EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
This project is a high-performance, browser-based Computer Vision and Smart 
Traffic Video Analytics platform. It delivers real-time spatial image processing,
classical feature extraction, semantic segmentation, deep learning object 
detection (YOLO), multi-object tracking (ByteTrack), and video motion dynamics
(dense/sparse optical flow, background subtraction).

The platform couples a high-throughput Python FastAPI backend with an ultra-modern,
dark glassmorphism Single Page Application (SPA) frontend.

4. FUNCTIONAL MODULE SPECIFICATIONS
--------------------------------------------------------------------------------

================================================================================
MODE A: STATIC IMAGE LAB (4 Modules)
================================================================================

Module 1: Preprocessing & Enhancement
--------------------------------------------------------------------------------
- Filters:
  * Gaussian Blur: 2D Gaussian kernel convolution with tunable kernel size
    (3 to 31) and standard deviation (sigma).
  * Median Filter: Non-linear salt-and-pepper noise reduction.
  * Laplacian Sharpening: High-boost edge enhancement via 2nd derivative operator.
  * Resize & Aspect Ratio Scaling: Linear/cubic interpolation (10% - 200%).
- Histograms:
  * 256-bin intensity distribution extraction for Grayscale and RGB channels.
  * Global Histogram Equalization: Cumulative distribution function linearization.
  * CLAHE: Contrast-limited adaptive histogram equalization for local contrast.
- Point Transformations:
  * Brightness (beta: -100 to +100) & Contrast (alpha: 0.1 to 3.0) scaling.
- Thresholding:
  * Global Otsu's optimal inter-class variance thresholding.
  * Adaptive Mean and Adaptive Gaussian local neighborhood thresholding.
- Mathematical Morphology:
  * Structuring Elements: Rectangular, Elliptic, and Cross kernels (3x3 to 15x15).
  * Operations: Erosion, Dilation, Opening, Closing, Morphological Gradient,
    Top-Hat, and Black-Hat.

Module 2: Feature & Edge Analysis
--------------------------------------------------------------------------------
- Gradients & Differential Operators:
  * Sobel (Horizontal Gx, Vertical Gy, and Combined Magnitude).
  * Scharr Operator (high-accuracy derivative for small 3x3 kernels).
  * Laplacian operator (nabla^2 f).
- Canny Edge Detection:
  * 5-Stage Pipeline: Gaussian smoothing -> Gradient magnitude & direction ->
    Non-Maximum Suppression (NMS) -> Dual-threshold hysteresis -> Edge tracking.
- Laplacian of Gaussian (LoG):
  * Multi-scale Gaussian smoothing followed by Laplacian zero-crossing detection.
- Line Geometry Detection:
  * Probabilistic Hough Transform (cv2.HoughLinesP) with customizable accumulator
    threshold, minimum line length, and maximum line gap.
- Corner & Interest Point Detectors:
  * Harris Corner Detector: Second moment auto-correlation matrix computation,
    with tunable eigenvalue sensitivity factor k (0.04 to 0.06).
- Invariant Local Descriptors:
  * SIFT (Scale-Invariant Feature Transform): Scale-space extrema in Difference-
    of-Gaussians (DoG) pyramids and 128-dimensional orientation descriptors.
- Shape Descriptors:
  * HOG (Histogram of Oriented Gradients): Multi-bin gradient orientation histograms
    computed across normalized spatial cells.

Module 3: Image Segmentation
--------------------------------------------------------------------------------
- Color Space Clustering (K-Means):
  * Unsupervised vector quantization in RGB or CIELAB color space.
  * Tunable cluster count k (2 to 10), max iterations, and convergence epsilon.
- Mean Shift Segmentation:
  * Spatial-color joint domain mode-seeking filtering (cv2.pyrMeanShiftFiltering).
- Seeded Region Growing:
  * 4-connected spatial growth initialized from image seeds using variance tolerance.
- Edge & Contour Segmentation:
  * Topological hierarchical contour extraction with bounding polygons and areas.

Module 4: Deep Learning Object Detection
--------------------------------------------------------------------------------
- Architecture:
  * Ultralytics YOLOv8n single-shot anchor-free convolutional neural network.
- Hyperparameter Tuning:
  * Confidence Score Threshold (0.10 to 0.95).
  * Non-Maximum Suppression (NMS) IoU Threshold (0.10 to 0.90).
- Output Analytics:
  * Visual bounding boxes with class labels and confidence badges.
  * JSON telemetry: Total object count, category frequency distribution table,
    and normalized bounding box coordinates.


================================================================================
MODE B: VIDEO & TRAFFIC ANALYTICS LAB (3 Modules)
================================================================================

Module 5: Video Telemetry & Temporal Keyframe Sampling
--------------------------------------------------------------------------------
- Video Stream Parsing:
  * Ingestion of MP4, AVI, MOV, and MKV streams via cv2.VideoCapture.
  * Metadata extraction: Frame resolution (Width x Height), Frame Rate (FPS),
    Total Frame Count, Playback Duration (s), and File Size (MB).
- Temporal Keyframe Extraction:
  * Uniform temporal decimation producing an indexed keyframe preview strip
    (e.g., frames 0, 48, 96, 144...) for rapid visual scene summarization.

Module 6: Multi-Object Detection & Tracking (YOLOv8 + ByteTrack)
--------------------------------------------------------------------------------
- Tracking Architecture:
  * ByteTrack data association algorithm integrated with YOLOv8.
  * Kalman Filter spatial state prediction + Hungarian bipartite assignment.
  * Association of both high-confidence and low-confidence detections to preserve
    track continuity through short occlusions.
- Frame Decimation & Performance:
  * Process every N-th frame (frame_step = 1 to 15) for high FPS throughput.
- Tracking Metrics:
  * Persistent Track IDs assigned per object (#1, #2, #3...).
  * Unique object count, active track list, category breakdown, and annotated
    temporal sample timeline.

Module 7: Motion Analysis & Optical Flow
--------------------------------------------------------------------------------
- Dense Optical Flow (Gunnar Farnebäck):
  * Computes pixel-level motion velocity vector field (u, v) between frames.
  * Visualization: HSV color mapping (Hue = Motion Angle, Value = Magnitude).
  * Quantitative telemetry: 8-direction polar motion distribution chart
    (N, NE, E, SE, S, SW, W, NW).
- Sparse Optical Flow (Lucas-Kanade):
  * Shi-Tomasi good features to track extraction.
  * Iterative pyramidal Lucas-Kanade feature tracking with colorized historical
    trajectory path trails.
- Background Subtraction:
  * MOG2: Improved Gaussian Mixture-based background/foreground segmentation
    with shadow detection.
  * KNN: K-Nearest Neighbors background model.
  * Motion Energy Curve: Graph of total foreground motion pixels over time.


5. REST API CONTRACT & DATA FORMATS
--------------------------------------------------------------------------------
All API endpoints return JSON containing execution metrics, telemetry arrays,
and Base64-encoded visual previews (Data URIs):

Standard Response Schema:
{
  "status": "success",
  "execution_time_ms": 38.4,
  "metrics": {
    "dimensions": {"width": 1280, "height": 720, "channels": 3},
    "summary": { "objects_count": 12, "classes": {"car": 8, "bus": 4} },
    "charts": {
      "histogram": [ ... ],
      "polar_flow": [ 12.5, 34.1, 45.0, 10.2, 5.0, 18.2, 22.1, 9.8 ]
    }
  },
  "images": {
    "original": "data:image/jpeg;base64,...",
    "processed": "data:image/jpeg;base64,..."
  }
}

Primary Endpoint Routes:
- POST /api/image/filter          # Spatial convolution filters
- POST /api/image/histogram       # Histograms & equalization
- POST /api/image/morphology      # Mathematical morphology
- POST /api/image/edges           # Canny, Sobel, Laplacian, LoG
- POST /api/image/features        # Harris, SIFT, HOG, Hough lines
- POST /api/image/segment         # K-Means, Mean Shift, Region Growing
- POST /api/image/detect          # YOLOv8 static image detection
- POST /api/video/info            # Video metadata & keyframe strip
- POST /api/video/detect          # YOLOv8 + ByteTrack object tracking
- POST /api/video/optical-flow    # Dense Farneback & Sparse Lucas-Kanade
- POST /api/video/bg-subtraction  # MOG2 & KNN background subtraction
- GET  /api/health                # Health check & status
